# MumbleWay

**Talk through the wind.**

A voice client for [Mumble](https://www.mumble.info/) servers, built for talking
from inside a motorcycle helmet at speed. Windows, macOS, iOS, iPadOS and
Android.

Wind is the hard part. At speed it is loud, broadband and relentless, and it
defeats the noise suppression in ordinary voice apps because that was tuned for
offices and cafes. MumbleWay's microphone chain is built for a different
problem.

- [Privacy policy](privacy.md)
- [Source code, and how to build it](https://github.com/zavitax/mumbleway)
- [Report a problem](https://github.com/zavitax/mumbleway/issues)

MumbleWay is free and open source. It is an independent client and is not
affiliated with the Mumble project.
